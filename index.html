04 // MENACES EXTÉRIEURES

Factions & acteurs hostiles

Les forces hors-site sont suivies par l'ISD et l'IA. Les protocoles de réponse sont déclenchés selon la menace.

CI
HOSTILE / PRIORITÉ 01

Chaos Insurgency

Faction paramilitaire ennemie principale. Raids de surface, infiltrations, libération des Classe-D, pillage de paratechnologie et sabotage du Réacteur Gen-V.

Base : FOB clandestine en forêt sibérienne
Hiérarchie : Conscript → Senior Conscript → Alpha → Beta → Delta → Cell Agent → Cell Director → Delta Command → Gamma Command → The Engineer
GRU-P
RÉSIDUS / INFILTRATION

Division « P » du GRU

Ancienne organisation soviétique. Les cellules résiduelles cherchent à pénétrer le Niveau S-1 afin de récupérer documents et artefacts contenus dans les archives.

Zone d'intérêt : Coffre des Archives GRU-P · S-1
GOC
TIERS-PARTIE / NEUTRE

Global Occult Coalition

Faction armée tierce appliquant une neutralité stricte. Elle peut intervenir pour détruire les SCPs si la Fondation perd le contrôle du Site-95.

Doctrine RP : observation → évaluation → intervention conditionnelle
