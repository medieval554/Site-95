Origines soviétiques

Le Site-95 a été construit au début des années 1990 sur les fondations d'un ancien complexe militaire souterrain exploité par la Division « P » du GRU, spécialisée dans la psychotronique et les recherches paranormales soviétiques.

Complexe voisin : Site-01

Un complexe hautement sécurisé situé sous la même chaîne montagneuse. Le Site-01 sert de résidence au Conseil O5 et de centre stratégique. Il est relié au Site-95 par un tunnel blindé : le Sas Alpha-1.

Codes d'Alerte & Protocoles

Classification des urgences du Site-95.

CODE 01

Code Vert

Situation nominale. Les activités normales, les recherches et les expérimentations sont autorisées.

CODE 02

Code Jaune

Émeute ou incident au CDC. Verrouillage automatique du Bloc Classe-D et intervention du Département de Sécurité.

CODE 03

Code Rouge

Brèche majeure ou raid ennemi. Fermeture des sas de transit, confinement des zones et mobilisation des FIM.

CODE 04

Code Noir

Procédure de dernier recours. Activation de l'Ogive Thermonucléaire Alpha conformément à l'autorité O5 applicable au scénario RP.

⚠ PROCÉDURE CODE NOIR

Le Code Noir représente le niveau d'urgence absolu du Site-95. Dans le cadre du lore du serveur, cette procédure entraîne l'activation de l'Ogive Thermonucléaire Alpha et l'annihilation thermique du complexe souterrain.
